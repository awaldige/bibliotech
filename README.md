# 📚 BiblioTech - Sistema de Gestão de Biblioteca

O **BiblioTech** é uma aplicação web completa para gerenciamento de bibliotecas, focada em simplicidade e eficiência. Desenvolvido para facilitar o controle de acervo, leitores, empréstimos e reservas.

Este projeto foi construído para demonstrar habilidades em integração Frontend/Backend, manipulação de bancos de dados relacionais e criação de interfaces dinâmicas (SPA Style).

## 🚀 Funcionalidades
- **Dashboard Inteligente:** Resumo de estatísticas e feed de atividades recentes em tempo real.
- **Gestão de Empréstimos:** Controle total de saídas, baixas e sistema de renovação rápida (+7 dias).
- **Controle de Acervo:** Cadastro e edição de Livros, Autores e Editoras com validação.
- **Interface Responsiva:** Modais modernos para edição de dados sem recarregar a página.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** HTML5, CSS3 (Variáveis CSS, Flexbox, Grid) e JavaScript Puro (Vanilla JS).
- **Backend:** PHP 8+ com arquitetura modular de APIs.
- **Banco de Dados:** MySQL.
- **Ícones:** Font Awesome 6.

## 📦 Como Instalar o Projeto
1. Clone este repositório ou baixe o ZIP.
2. Coloque os arquivos na pasta `htdocs` do seu servidor local (XAMPP/WAMP).
3. Importe o arquivo SQL (disponível na pasta `/sql`) para o seu banco de dados MySQL.
4. Ajuste as credenciais de acesso no arquivo `api/config.php`.
5. Acesse `localhost/bibliotech` no seu navegador.
