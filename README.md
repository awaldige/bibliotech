# 📚 BiblioTech - Sistema de Gestão de Biblioteca

O **BiblioTech** é uma aplicação web completa para gerenciamento de bibliotecas, desenvolvida para facilitar o controle de **acervo, leitores, empréstimos e reservas**.

O projeto demonstra integração entre **Frontend e Backend**, manipulação de banco de dados relacional e desenvolvimento de interfaces dinâmicas e responsivas.

---

## 🚀 Funcionalidades

* **Dashboard:** Visualização de estatísticas e atividades recentes.
* **Gestão de Empréstimos:** Controle de empréstimos, devoluções e renovação de livros.
* **Controle de Acervo:** Cadastro e gerenciamento de livros, autores e editoras.
* **Gestão de Usuários:** Administração dos usuários da biblioteca.
* **Reservas:** Controle de reservas de livros.
* **Interface Responsiva:** Layout adaptado para diferentes tamanhos de tela.
* **Interface Dinâmica:** Utilização de modais e requisições sem necessidade de recarregar toda a página.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3 e JavaScript Vanilla
* **Backend:** PHP 8+
* **API:** PHP com arquitetura modular
* **Banco de Dados:** MySQL
* **Ícones:** Font Awesome 6

## 📦 Como Instalar o Projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/awaldige/bibliotech.git
```

### 2. Configurar o servidor local

Coloque os arquivos do projeto na pasta `htdocs` do **XAMPP** ou no diretório correspondente do seu servidor PHP.

### 3. Configurar o banco de dados

Importe o arquivo SQL disponibilizado no projeto para o **MySQL**.

Caso o arquivo esteja na raiz do projeto:

```text
biblioteca.sql
```

### 4. Configurar a conexão

Ajuste as credenciais do banco de dados no arquivo:

```text
api/config.php
```

### 5. Acessar o sistema

Com o servidor Apache e o MySQL em execução, acesse:

```text
http://localhost/bibliotech/
```
